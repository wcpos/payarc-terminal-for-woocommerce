# PayArc Terminal for WooCommerce 0.1.5

This is the first packaged release produced by the automated release workflow. It also hardens the plugin's logging.

## Changed

- Diagnostic logging is written to the WooCommerce status logs (WooCommerce → Status → Logs, source `payarc-terminal-for-woocommerce`) with secrets redacted. Provider error messages and exception text are now redacted aggressively so a PayArc-returned credential cannot leak into an error, while the plugin's own log messages are redacted precisely so ordinary text is no longer mangled.
- The untrusted-text redaction used by the connection and AJAX error paths now shares a single implementation, so the two cannot drift apart.

## Added

- A `patwc_logging` filter to turn plugin logging off:

  ```php
  add_filter( 'patwc_logging', '__return_false' );
  ```

## Internal

- Added continuous integration (lint + regression tests on PHP 7.4 and 8.3) that runs on every pull request.
- Added an automated release workflow that tags the version, builds the plugin ZIP, and publishes a GitHub release from `docs/releases/<version>.md`.

## Notes

- No configuration changes are required.
