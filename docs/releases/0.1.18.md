# 0.1.18

## Fixed

- **Stale payment details after the 0.1.17 order re-read, on stores with HPOS
  data caching.** 0.1.17 re-reads the order before completing a payment. With
  WooCommerce's HPOS data caching on and a persistent object cache,
  WooCommerce keeps an order's cached meta when the cached order row has
  already expired. The re-read then saw the paid order with the PayArc payment
  still in progress. Stock was not reduced twice. But a status check could
  ask PayArc again and add a second "final status: success" note. And when a
  different PayArc transaction had already paid the order, the plugin did not
  report the conflict. The plugin now clears the order's cached meta itself.
  Stores without HPOS data caching were not affected.
