# 1.0.0

PayArc Terminal 1.0.0 is the release for WCPOS 2.0. It needs WooCommerce POS Pro 2.0.0 or newer: without it, the plugin shows an admin notice and adds no payment method. PayArc Terminal is now for staff on the POS only, and you switch it on in POS → Settings → Checkout.

## Changed

- **WooCommerce POS Pro 2.0.0 or newer is required.** Without it, the plugin shows an admin notice and does nothing else.
- **Not offered on your shop's checkout.** The "Enable PayArc Terminal on the online checkout" checkbox is gone, and a value saved for it no longer counts. The Enabled toggle on the WooCommerce Payments list has no effect either.
- **Switch it on in POS → Settings → Checkout.** With it on, staff can take PayArc payments in the POS app and on the order-pay page.
- **The order-pay page shows WCPOS Pro's payment panel.** A PayArc sale started before the upgrade is picked up by that panel. If PayArc cannot see that sale under your current PayArc credentials, the page says so and asks you to check the PayArc dashboard first.
- **Refunds from WooCommerce go to the terminal.** Refunding a PayArc payment taken through WCPOS Pro sends a terminal refund to PayArc, and the outcome is noted on the order. A payment taken before the upgrade by the plugin's own order-pay panel is still refunded from the PayArc dashboard or the terminal, as before.

## Fixed

- **A refund PayArc does not answer is asked about again** until PayArc answers. If it still does not, staff are told to check the PayArc dashboard.
- **A refund PayArc accepted no longer stays pending for ever** when its outcome never arrives. The plugin checks with PayArc again after 1, 5, 15 and 60 minutes and notes the outcome on the order. If it is still unknown after that, a note asks you to verify it in PayArc.
