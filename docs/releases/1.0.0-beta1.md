# PayArc Terminal for WooCommerce 1.0.0-beta1

First beta of 1.0.0, for the WCPOS 2.0 beta. A prerelease: install the zip by hand on a test store, with the WCPOS 2.0 beta plugin, Pro and app already in place.

The extension now runs on WCPOS Pro 2.0's shared payments base and requires WCPOS Pro 2.0.0 or later. Without a compatible Pro it shows an admin notice and registers nothing.

## Changed

- A server adapter drives a PayArc PAX terminal through Pro's ledger: a sale per ledger row (the row id is the idempotency key), polling by `traceId`, cancellation, authenticated callbacks on Pro's route, and refunds as terminal commands.
- A refund PayArc does not answer is asked about again under the same idempotency key until PayArc answers or staff are told to check the PayArc dashboard; the refund's terminal outcome is noted on the order.
- The gateway is POS-only: it is never offered on the shop's checkout.
