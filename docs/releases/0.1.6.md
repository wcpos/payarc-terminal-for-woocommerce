# PayArc Terminal for WooCommerce 0.1.6

This release adds Live PayArc mode support and safeguards merchants from mixing Test and Live credentials.

## Added

- Added PayArc Live/Test mode selection, with Live as the default mode for production terminal use.
- Added environment-specific PayArc endpoint selection for Connect Login, Connect API, and Merchant API calls.
- Added credential mismatch warnings: if Live credentials are entered while Test is selected, or Test credentials are entered while Live is selected, Connect PayArc warns the merchant to switch modes without exposing submitted secrets.
- Added a stored, non-secret connection fingerprint that binds saved Connect tokens and terminal registries to the selected mode and PayArc credentials.

## Changed

- Live mode now requires a fresh Live connection and an HTTPS runtime callback URL before the gateway can be enabled.
- Connect, Disconnect, terminal refresh, mode changes, credential saves, and callback-token changes are blocked while PayArc terminal payments are in flight.
- Terminal refresh/reconnect now clears stale default terminal IDs when PayArc returns no valid terminals.
- Stale in-flight payment markers are pruned so old abandoned attempts do not block future PayArc connection changes indefinitely.

## Notes

- **Live is now the default mode.** Merchants using sandbox credentials must explicitly select Test before connecting, or the plugin will warn that the credentials appear to belong to the opposite environment.
- Before enabling Live mode, confirm the callback/webhook URL shown by the gateway is HTTPS and reachable from PayArc.
